# ADR-0001: SubForge 定位为窄而深的同人音声翻译工具

SubForge 最初按大众工具方向宣传（README 写「同人音声/播客/视频一键字幕」，ASMR 被称作「添头」）。2026-08 grilling 后确认真实定位：**以同人音声（RJ 号）为核心受众的个人翻译工具，日→中双语字幕，ASMR 耳语优化是核心差异能力而非附属功能**。由此落定以下决策：

- **ASMR 预设 = 核心护城河**：受众圈（同人音声）的主力作品恰恰是 ASMR 耳语内容，普通字幕工具做不好耳语识别，`--asmr` 预设是差异点。
- **多目标语言明确不做**：受众只有日→中的需求；且实现上只是改提示词，真需要时随时可加，故永久垫底。
- **Deepgram 云端 ASR 保留**：当初为质量引入（`--asr-provider deepgram`），既有实现就保留为质量选项，不因「本地/离线」定位而移除；代价是上传音频与 API 费用，文档已注明。
- **个人优先、开源公开**：核心用户只有作者本人；代码开源（MIT）别人可自用，但不承诺社区服务与路线承诺。
- **只做本地形态**：作品库（阶段 2）与实时翻译（阶段 3）均为本机运行，不做公网展示站——避免商业 RJ 作品的版权风险（DLsite 条款）。

_Status: accepted_（2026-08-12）
