| [ADR-0002](0002-library-filesystem-authority.md) | Library 文件系统是事实来源，导入只复制不移动 | accepted（2026-08-13） |

## 决策速览

- **ASMR 预设 = 核心护城河**：受众主力是 ASMR 耳语作品，`--asmr` 是差异点而非添头
- **多目标语言明确不做**：受众只有日→中；实现只是改提示词，随时可加，故永久垫底
- **Deepgram 保留为质量选项**：代价（上传音频、API 费用）已在文档注明
- **只做本地形态**：作品库与实时翻译均为本机运行，不做公网展示站，规避商业 RJ 作品的版权风险
- **文件系统优先于数据库**：SQLite 只做可删除重建的索引，媒体/字幕/断点是文件资产，可整体换盘
