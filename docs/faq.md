# 常见问题

## 识别

??? question "耳语、悄悄话的部分大段没有字幕？"

    用**本地 Whisper** 识别时，确认场景是「**ASMR 悄悄话强化**」（处理窗口里可以临时切换，默认值在「设置 → 默认模型」；命令行加 `--asmr`）。它会放大小音量、降低“静音”判定门槛，尽量保住耳语和气音。

    这个选项只对本地 Whisper 有效，所以选在线音频模型或 Deepgram 时不会显示。
    还是有漏的话，用[片段重跑](segment-reprocess.md)框住那一段，换在线音频模型（如 Gemini）重新识别。

??? question "结尾多出「ご視聴ありがとうございました」这种句子？"

    识别模型在静音段“脑补”出来的，[校对模式](subtitle-revision.md)里直接删掉即可。新处理的音轨已经会自动过滤大部分这类句子。

??? question "本地 Whisper 模型下载失败？"

    模型托管在 Hugging Face，国内网络可能需要代理：在「设置 → 网络代理设置」填上代理地址。
    也可以手动下载好模型文件夹（里面有 `model.bin` 和 `config.json`），在设置里直接指定这个文件夹，完全离线使用。

??? question "一条音轨被标成「无语音」？"

    说明这条音轨里没识别到人声，例如纯音效、纯 BGM 音轨。这是正常结果，不是出错。如果确实有人声：用本地 Whisper 的话，确认场景是「ASMR 悄悄话强化」后重新处理；也可以换在线音频模型试试。

??? question "没有显卡能用吗？"

    能。两种办法：用 CPU 跑本地 Whisper（慢不少）；或者用 Gemini 这类在线音频模型识别，完全不用本机显卡。

## 翻译

??? question "翻译出来有空行，或只翻了一半？"

    SubForge 会自动补翻缺失的句子。如果最后任务还是失败了，去[任务中心](tasks.md)点「重试」，只会补翻没完成的部分，不会从头来。

??? question "想换个模型重新翻译，又不想重新识别？"

    在作品详情页点「处理」，处理方式选「**仅重新翻译**」。

??? question "人名、专有名词总是翻错？"

    在「设置 → 全局翻译 Prompt 提示词」里写上固定译法，例如「みやぢ 译为 宫地」。

## 作品库

??? question "导入会改动我原来的文件吗？"

    不会。导入是**复制**一份到作品库，原文件不会被移动、修改或删除。在 SubForge 里删除作品，也只是挪进作品库的 `.trash` 回收站文件夹。

??? question "作品库能换个硬盘吗？"

    能。把整个作品库文件夹复制到新位置，然后在「设置 → 本地媒体库目录」里重新选一下就行。

??? question "DLsite 信息获取失败？"

    多半是网络问题：在「设置 → 网络代理设置」填上代理。也请确认 RJ 号是对的（`RJ` 加 6~8 位数字）。

??? question "同一个声优出现了两次？"

    在「创作者」页点「管理」，把两个合并成一个即可。之后再导入同名的，会自动归到同一个人。

## 任务

??? question "关掉软件后任务还在吗？"

    在。下次启动时没跑完的任务会自动继续，片段重跑的待确认结果也都还在。

??? question "提交了片段重跑，但没看到结果？"

    重跑在后台进行。去「任务中心」看进度，完成后状态变为「待确认」，点「查看候选」确认。

## 其他

??? question "手机或其他电脑能访问吗？"

    不能。为了安全，工作台只允许本机访问。

??? question "怎么检查环境有没有问题？"

    在终端运行 `subforge check`，它会逐项检查 Python、ffmpeg、显卡和模型连通性，并告诉你哪里有问题。
