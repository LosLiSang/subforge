## 一、全局外壳与常驻组件

### 1. 侧边栏导航 (Sidebar)

* **展示内容**：
  * **品牌区域**：SubForge Logo 图标、主标题 `SubForge`、副标题 `音声工坊`。
  * **导航路由链接**：
    * 作品库 (`/`) — 图标 + 标题
    * 翻译配置 (`/profiles`) — 图标 + 标题
    * 创作者 (`/creators`) — 图标 + 标题
    * 设置 (`/settings`) — 图标 + 标题
    * 统计 (`/stats`) — 图标 + 标题
    * 任务中心 (`/tasks`) — 图标 + 标题 + 运行中任务数量小红点/数字徽章
    * 关于 (`/about`) — 图标 + 标题
  * **底部外观控制器**：
    * 6 色强调色选择器（Blue, Cyan, Green, Violet, Amber, Rose）
    * 主题明暗切换按钮（黑色主题 / 白色主题）

### 2. 全局常驻播放底栏 (GlobalPlayerBar)

* **触发条件**：全局有音轨正在播放或处于暂停载入状态时常驻视口底部。
* **展示内容**：
  * **左侧元数据区**：
    * 当前音轨所属作品封面微缩图（带圆角边框，点击跳转播放页）
    * 当前音轨标题
    * 作品标题与 RJ 号小字
  * **中间核心控制区**：
    * 单曲循环开关（Repeat 图标）
    * 快退 10 秒（RotateCcw + "-10" 徽标）
    * 核心播放 / 暂停圆钮（大号白底按钮，带投影）
    * 快进 30 秒（RotateCw + "+30" 徽标）
    * 时间轴与进度条：当前播放时间（`00:00`）、细腻填充色渐变滑块、总时长
  * **右侧工具群**：
    * 播放倍速切换药丸（`0.75x` / `1.0x` / `1.25x` / `1.5x` / `2.0x` 循环）
    * 睡眠定时器弹出面板与徽章（支持关闭、15m、30m、45m、60m、当前音轨结束）
    * 音量调节组：喇叭静音/取消静音按钮、0%~300% 硬件增益滑块、百分比数字显示
    * 悬浮台本歌词开关按钮（"词"）
    * 展开独立全屏双语播放页按钮（`Maximize2` 图标）

### 3. 桌面悬浮歌词条 (FloatLyrics)

* **展示内容**：
  * 悬浮于界面右下角的独立毛玻璃微缩窗。
  * 顶部操作条：拖拽握把、关闭按钮。
  * 双行字幕展示：
    * 上行：当前时间点日文原声台本
    * 下行：当前时间点高亮中文译文

## 二、核心功能页面清单

### 1. 作品库首页 (Library)

* **路由**：`/`
* **接口**：`GET /api/library/items?page=1&limit=12&sort=...&q=...&tag=...&creator=...`
* **展示内容**：
  1. **页面头部与工具栏**：
     * 页面主标题 `作品库`
     * 快速搜索输入框（支持按作品标题、原名、RJ 号模糊搜索）
     * 创作者筛选下拉框（全部创作者 / 各声优社团及包含作品数）
     * 视图模式切换（海报网格视图 `LayoutGrid` / 详细列表表格视图 `List`）
     * 操作按钮组：`导入音频`、`导入文件夹`、`从链接下载`
  2. **继续收听横幅 (Continue Listening Shelf)**：
     * 仅在本地存储有未听完音频记录时显示。
     * 展示：作品封面小图、作品标题、音轨名称、已收听百分比进度条、剩余时长提示。
     * 操作：一键「恢复播放」、关闭/清除记录按钮。
  3. **字幕状态筛选药丸条 (Subtitle Status Filter)**：
     * `全部`、`双语已就绪 ✓`（绿色胶囊）、`仅中字`、`仅日文`、`未转写`。
  4. **作品主体视图**：
     * **海报网格视图 (Grid View)**：
       * 竖向 3:4 比例作品封面（悬停微缩放）
       * 封面左上角：`RJ号` 徽章（如 `RJ123456`）
       * 封面右上角：字幕就绪状态胶囊（中日双语/仅原文/未转写）
       * 封面右下角：作品总体积大小
       * 封面悬停时：中心浮现「一键播放第一轨」大圆钮
       * 卡片底部文字区：作品标题（最多两行省略）、声优与社团标签（最多2个）
     * **详细列表视图 (List View)**：
       * 表格列：封面微缩图、标题与原名及RJ号、创作者标签组、字幕就绪徽章、大小与音轨数、快捷操作组（播放第一轨、查看详情）。
  5. **底部分页器 (Pagination)**：
     * 总作品数统计、当前页码/总页码。
     * 上一页、数字页码按钮、下一页。
  6. **模态弹窗 (Modals)**：
     * 单个音频导入弹窗（文件选择器、标题、RJ号、创作者选择）
     * 文件夹批量导入弹窗（目录路径选择、自动归组预览）
     * 链接下载导入弹窗（URL 粘贴、下载并自动导入）

### 2. 作品详情页 (ItemDetail)

* **路由**：`/items/:id`
* **接口**：`GET /api/items/{id}`
* **展示内容**：
  1. **返回导航**：`← 返回作品库`。
  2. **沉浸式毛玻璃 Hero 横幅**：
     * 背景层：以当前作品封面进行高斯模糊暗化处理的大幅全宽背景。
     * 左侧：高保真原尺寸封面海报、`RJ` 徽章。
     * 右侧主体信息：
       * 作品主标题、日文原名（斜体弱化显示）。
       * 元数据芯片：RJ 号（带外部跳转图标，直达 DLsite 官网页面）、创作者标签（声优/社团）、总音轨数、标签云（`#标签`）。
       * 字幕生成进度条：已完成双语字幕音轨数 / 总音轨数，附带动态百分比进度槽。
     * 操作按钮栏：
       * `▶ 开始播放`（高亮主按钮，播放第一轨）
       * `⚡ 处理未完成音轨`（呼出全局流水线任务发起弹窗）
       * `✏️ 编辑作品`（修改标题、原名、RJ号、声优社团、标签）
       * `🖼️ 更换封面`（呼出本地系统文件选择器更新封面）
       * `🗑️ 删除作品`（将作品移入回收站）
  3. **数据概览卡片组 (Overview Stats Grid)**：
     * 音轨总数、总时长、总大小、可播放数、处理中数、失败数。
  4. **音轨列表 (Tracklist)**：
     * 序号、就地播放小圆钮（当前播放轨展示音波/暂停动画）。
     * 音轨状态徽章（`playable` / `queued` / `processing` / `failed`）。
     * 时长标签（如 `05:24`）、文件大小。
     * 字幕状态徽章（`双语 ✓` / `日文 ✓` / `未转写`）。
     * 音轨标题（可点击立即就地播放）。
     * 独立操作工具栏：
       * `播放台本`（跳转至沉浸式双语播放页）
       * `处理…`（针对该单轨发起 ASR 与 LLM 翻译）
       * `下载字幕`（若已生成中文/日文字幕，直接导出 `.srt` 文件）
       * `删除音轨`。

### 3. 沉浸式双语播放器 (Player)

* **路由**：`/tracks/:trackId/play`
* **接口**：
  * `GET /api/tracks/{trackId}/subtitles`
  * `POST /api/tracks/{trackId}/subtitles/edit`
  * `POST /api/tracks/{trackId}/segments/reprocess`
* **展示内容**：
  1. **返回导航**：`← 返回作品`。
  2. **顶部作品与音轨横幅**：
     * 封面缩略图、当前音轨标题、所属作品名称、RJ 号、声优社团徽章。
  3. **音频播放控制条**：
     * 播放/暂停按钮、进度条滑块、当前播放时间 / 总时长。
  4. **字幕模式切换与校对控制栏**：
     * 模式按钮组：`双语对照`、`仅原文`、`仅译文`。
     * 校对模式切换按钮：`✏️ 校对模式`。
     * `📍 定位当前句` 快捷按钮（当用户手动滑动翻阅台本时，一键平滑滚回正在播放的句子）。
  5. **大字号当前句高亮预览盒 (Subtitles Quick Box)**：
     * 日文原文大字号预览。
     * 中文翻译大字号高亮预览。
  6. **苹果音乐风格沉浸式台本视区 (Bilingual Script Flow)**：
     * 每一句字幕卡片：
       * **左侧**：等宽字体时间戳（如 `02:14`），点击精准跳转至该时间播放。
       * **中间文本**：
         * 日文原句（青蓝色字体，字号 13.5px）
         * 中文译文（高对比度纯白字体，字号 15.5px，当前朗读行加粗并放大至 16.5px）
       * **激活态效果**：当前播放行自动居中滚动，背景带有柔和蓝色光晕与高对比度。未激活行半透明淡化，鼠标悬停时恢复清晰。
       * **行级浮动快捷工具栏 (Hover Line Tools)**：
         * `[-0.5s]` / `[+0.5s]`：时间轴起止点微调。
         * `⚡ 重跑`：预填起止时间，一键呼出当前句局部重新识别与翻译弹窗。
         * `✏️ 校对`：切换该行内联输入框，实时修改保存原文与译文。
  7. **局部疑难音频重跑弹窗 (Segment Reprocess Modal)**：
     * 起始时间（秒）、结束时间（秒）。
     * ASR 模型配置选择下拉框（Whisper / Deepgram / Gemini）。
     * LLM 翻译模型配置选择下拉框。
     * 提交重跑按钮。

### 4. 任务中心 (Tasks)

* **路由**：`/tasks` 与 `/downloads`
* **接口**：`GET /api/tasks`, `GET /api/downloads/history`, `POST /api/tasks/{id}/cancel`, `POST /api/tasks/{id}/retry`
* **展示内容**：
  1. **页面头部**：`任务中心`，副标题监控后台 ASR、LLM 与下载进度，右上角「刷新状态」按钮。
  2. **选项卡 (Tabs)**：
     * `字幕任务 (N)`：正在排队、转写、翻译或重跑的音频任务。
     * `下载任务 (N)`：通过链接下载的音视频任务。
  3. **字幕任务卡片**：
     * 任务所属作品标题、音轨名称。
     * 状态徽章（`queued` 排队中 / `running` 处理中 / `completed` 已完成 / `failed` 失败）。
     * 处理流水线阶段提示（如 `ASR: faster-whisper (35%)`、`LLM: 正在翻译第 3/10 批次`）。
     * 动态进度条与百分比数字。
     * 操作：取消任务、重试失败任务、删除任务记录。
  4. **下载任务卡片**：
     * 下载来源 URL、下载进度与速度、目标文件路径、取消/重试按钮。

### 5. 模型与翻译配置 (Profiles)

* **路由**：`/profiles`
* **接口**：`GET /api/profiles`, `POST /api/profiles`, `POST /api/profiles/{id}/test`
* **展示内容**：
  1. **页面头部**：`翻译配置`，副标题「管理 ASR 语音识别引擎与 LLM 翻译模型」，右上角「新建配置」按钮。
  2. **选项卡 (Tabs)**：
     * `ASR 语音转写配置`：用于将日语音频转为文本时间轴。
     * `LLM 翻译模型配置`：用于将日文原文翻译为中文双语台本。
  3. **配置卡片列表**：
     * 配置名称、引擎提供商标识（`faster-whisper`, `deepgram`, `gemini`, `openai-compatible`）。
     * 模型名称（如 `large-v3`, `nova-3`, `gpt-4o-mini`, `deepseek-chat`）。
     * 接口 Base URL（若为远程 API）。
     * 设备与量化模式（`cuda` / `cpu`, `float16` / `int8`）。
     * 操作控件组：
       * `测试连接`（实时发起测试并显示延迟毫秒数与成功/失败结果）。
       * `删除配置`。
  4. **新建配置弹窗 (Add Profile Modal)**：
     * 选择配置类型（ASR 还是 LLM）。
     * 配置名称、提供商下拉选择、模型 ID、API Key（密文输入）、Base URL、并发限制。

### 6. 创作者管理 (Creators)

* **路由**：`/creators`
* **接口**：`GET /api/creators/list`, `POST /api/creators`, `POST /creators`
* **展示内容**：
  1. **页面头部**：`创作者`，副标题「管理声优与同人社团」，右上角「新建创作者」按钮。
  2. **搜索与分类筛选**：
     * 创作者名称搜索框。
     * 分类筛选选项卡：`全部`、`声优 (Voice Actor)`、`社团 (Circle)`。
  3. **创作者列表行**：
     * 创作者类型徽章（声优 / 社团）。
     * 创作者名称。
     * 关联作品数量胶囊（可点击直接跳转作品库并按该创作者筛选）。
     * 操作按钮：`重命名`、`删除`。
  4. **弹窗**：
     * 新建创作者弹窗（姓名输入、类型单选）。
     * 重命名创作者弹窗。

### 7. 系统设置 (Settings)

* **路由**：`/settings`
* **接口**：`GET /api/settings`, `POST /settings`, `POST /library/select`
* **展示内容**：
  1. **媒体库根目录设置**：
     * 当前配置的本地媒体库绝对路径展示。
     * `选择文件夹` 按钮（调用本地系统原生文件选择对话框）。
  2. **网络代理设置**：
     * HTTP / HTTPS 代理地址输入框（如 `http://127.0.0.1:7890`）。
  3. **并发与性能流水线配置**：
     * 本地 ASR 并发线程数（默认 1，防止显存溢出）。
     * 远程 ASR 并发请求数（默认 1）。
     * LLM 翻译 Worker 并发数（默认 8）。
  4. **全局翻译 Prompt 模板**：
     * 多行文本输入区，允许自定义 ASMR / 同人音声场景下的翻译风格提示词、专有名词约定。
  5. **访问安全与鉴权**：
     * 固定访问 Token 配置。
     * 局域网无鉴权访问模式开关。
  6. **外部服务密钥**：
     * Deepgram API Key 配置。
  7. **保存按钮**：底部「保存设置」主按钮，保存成功后浮现绿色提示。

### 8. 数据统计 (Stats)

* **路由**：`/stats`
* **接口**：`GET /api/stats`
* **展示内容**：
  1. **指标看板网格 (Stats Metric Grid)**：
     * 作品总数 (Total Items)
     * 音轨总数 (Total Tracks)
     * 媒体总时长 (Total Duration，如 `128:45:20`)
     * 已生成字幕音轨数 (Subtitled Tracks)
     * 创作者总数 (Total Creators)
  2. **音轨状态完成度进度条**：
     * 可播放 / 已完成字幕音轨进度条与百分比（如 `85.4%`）。
     * 待处理音轨数量。

---

### 9. 关于页面 (About)

* **路由**：`/about`
* **展示内容**：
  * SubForge 品牌图标与版本号（如 `v0.5.0`）。
  * 产品定位简介：「面向同人音声与 ASMR 的本地字幕翻译工作台」。
  * 技术架构清单：
    * 前端：React 19 + TypeScript + Vite + Lucide Icons
    * 后端：FastAPI + Starlette + Uvicorn + Pydantic
    * 语音识别：faster-whisper / Deepgram / Google Gemini Audio
    * 翻译引擎：OpenAI-Compatible LLMs (DeepSeek, Qwen, Claude, GPT)
  * 开源协议与 GitHub 仓库跳转链接。
