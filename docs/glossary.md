# 术语表

唯一事实来源是仓库根目录的 [`CONTEXT.md`](https://github.com/LosLiSang/subforge/blob/main/CONTEXT.md)，本页是文档用语的速查。**避免使用每条下的 _Avoid_ 项。**

## 领域对象

| 术语 | 定义 |
|------|------|
| **作品（Item）** | 一部可在 DLsite 购买的日文音声商品，SubForge 处理的基本单位 |
| **RJ 号** | DLsite 分配的唯一编号（形如 RJ01499022），用于识别作品、抓取封面 |
| **台本** | 作品随附的台词文本（シナリオ）；多数作品没有，没有就必须走 ASR |
| **Library** | 当前打开的本地归档根目录；文件系统资产与 `metadata.json` 是事实来源 |
| **Library Item** | 归档内容，只能是 RJ 作品或直播归档，拥有一个或多个 Track |
| **RJ 作品** | 由唯一 RJ 号标识的 Item；同一 RJ 再次导入会增加 Track |
| **直播归档** | 由作者/博主标识的直播音频 Item；第一版只接收音频 |
| **Track** | Item 内可独立处理和播放的媒体文件，及其源字幕、翻译字幕与断点状态 |
| **创作者** | 可复用的独立实体，内部 ID 区分同名；身份为社团或声优（互斥） |
| **导入来源** | URL 导入产生的不可变记录，保存原始链接；可查看但不覆盖 |
| **归档副本** | 导入后在 Library 内管理的媒体副本，处理与播放都针对它 |
| **导入** | 把所选媒体复制并校验到 Library；永不移动/修改/删除来源文件 |

## 处理

| 术语 | 定义 |
|------|------|
| **ASR 阶段** | 从音频生成源语言字幕的语音识别步骤，无台本作品的必经之路 |
| **源语言字幕 / 翻译字幕** | 同一作品的日文 SRT 与中文 SRT，合称**双语字幕** |
| **ASMR 预设** | `--asmr` 一键参数组（低阈值 VAD + 响度归一化 + 幻觉抑制），核心差异能力 |
| **任务** | 一个媒体文件的一次完整处理（ASR → 时间轴修正 → 翻译 → 输出） |
| **断点状态** | 任务的可恢复进度记录；CLI 在 `~/.subforge/jobs/`，Library Track 随 Item 保存 |
| **无语音完成** | ASR 无可用字幕段的正常终态（`no_speech`），不是失败 |
| **处理事件** | 管线发布的结构化状态与进度消息，不等同于日志 |

## Library UI

| 术语 | 定义 |
|------|------|
| **任务中心** | 统一展示下载、导入、ASR、翻译、排队、重试、候选评审状态的页面 |
| **字幕校正** | 用户直接修改正式字幕的内容、时间与结构，沉淀为双语内容资产 |
| **片段重处理** | 选一段连续时间范围重新生成候选；确认后才替换正式字幕 |
| **候选字幕** | 片段重处理生成、尚未确认的临时结果；不参与播放和导出 |
| **原生音频模型** | 可直接理解音频的多模态模型类别（如 Gemini）；统一为带 `transcribe` 能力的模型 Profile |
