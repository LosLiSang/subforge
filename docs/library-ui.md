# Library 工作台

```bash
subforge ui
```

首次启动会打开浏览器并要求选择 Library 根目录。服务只监听 `127.0.0.1`。

Library 是 SubForge 当前打开的本地归档根目录：文件系统资产与每个 Item 的 `metadata.json` 是事实来源，SQLite 仅作可删除重建的索引（见 [ADR-0002](adr/0002-library-filesystem-authority.md)）。一次只打开一个 Library。

## 导入

- **单媒体导入**：选择音频或视频文件；音频复制进 Library，视频提取 M4A AAC 后校验入库
- **RJ 文件夹导入**：递归扫描作品目录，把支持的音频作为 Track 导入，常见视频转 M4A AAC；批次允许部分成功
- **URL 导入**：产生不可变记录（保留原始链接），异步拉取封面；可选择导入后自动进入字幕处理队列

!!! warning "原文件永不改动"

    导入始终**复制音频 / 提取视频音轨**并校验到 Library，SubForge 永不移动、修改或删除来源文件；Library 内删除也只移动到 `.trash`。

## 作品与 Track

- **RJ 作品**：由 RJ 号标识，可关联多个社团/声优
- **直播归档**：由作者标识，只能关联声优
- **Track**：一个可独立处理和播放的媒体文件，以及关联的源字幕、翻译字幕与断点状态

作品页可以一键处理未完成音轨、自定义处理（继续 / 重新翻译 / 从头处理）、重命名、软删除。

## 播放器

- 双语 / 仅原文 / 仅译文 / 关闭四种字幕模式
- 全部字幕列表：勾选连续多条可直接发起[片段重处理](segment-reprocess.md)
- 悬浮歌词、全局播放栏、自动连播下一 Track

## 任务中心

统一展示媒体下载、导入、字幕处理与模型状态。字幕 Tab 置首，含排队、ASR、翻译、限流重试、片段重处理与候选评审入口，详见[任务中心](tasks.md)。

## 设置

- ASR 并发、翻译并发、全局翻译提示词
- 模型缓存目录、`medium`/`large-v3` 直接模型目录（离线）
- 模型下载代理、TLS 校验、自定义 CA
- 模型 Profile（统一配置）与音频连通性测试
