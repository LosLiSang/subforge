# 处理管线与 ASMR 预设

## 管线

```text
Audio / Video → ASR → Timeline Fix → LLM Translate → .srt
```

1. **ASR**：把音频转成源语言（日文）字幕条目
2. **时间轴修正**：合并过短字幕段（`merge_short_entries`）、修正字幕间距（`adjust_gaps`）
3. **写入源语言 SRT**
4. **翻译**：按批次并发翻译，带前后上下文；批次结果逐批落断点
5. **写入翻译字幕**

## ASMR 预设（核心差异能力）

`--asmr` / 场景选 ASMR 时启用整套耳语友好参数：

| 参数 | 值 | 解决什么 |
|------|-----|---------|
| VAD 阈值 | 0.2 | 耳语能量低，默认阈值会整段吞掉 |
| 最短语音段 | 100ms | 保留短促气音、吸气 |
| 最短静音间隔 | 300ms | 句子切分更细腻 |
| 语音前后 padding | 600ms | 防止首尾辅音被裁 |
| 单段上限 | 20s | 抑制长独白的幻觉漂移 |
| 上一段作为提示 | 关 | 防止幻觉逐句传播 |
| Whisper 静音阈值 | 0.3 | 低音量更不易被判成静音 |
| ffmpeg 响度归一化 | loudnorm | 耳语常在 -40~-50dB，VAD 区分不了 |

双声道（ASMR 双耳录音）会**拆左右声道分别转写**，再按时间窗选语音侧合并——平均混音会把语音能量砍半导致整段丢失。

## ASR 后端

| 后端 | 适用 |
|------|------|
| `local`（faster-whisper） | 默认，本地/离线，隐私友好 |
| `deepgram` | 云端质量选项；上传音频、产生费用 |
| 模型 Profile（Gemini 类） | 见[模型配置](model-profiles.md)，长音频自动分片 |

## 翻译

- OpenAI 兼容 `/chat/completions`，批次大小、上下文条数、并发可配
- 每批带前后源文上下文，保证人称与剧情连贯
- **语义空响应防护**：推理模型吃满预算或未按 `[N]` 前缀输出时，最多 3 次语义重试并串行化，绝不把空批次当成功缓存
- 个别行缺失时按 5 条/1 条递进补翻，而不是整批重来

## 无语音终态

ASR 没有产生可用字幕段时进入 `no_speech`：**这是正常终态**，不进入翻译、不生成空字幕，Track 仍可播放，调整设置后可重新处理。
