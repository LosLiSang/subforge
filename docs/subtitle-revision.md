# 字幕校正

自动生成的字幕值得沉淀为**可长期维护的双语内容资产**。SubForge 提供安全校正、结构编辑与快照恢复。

## 校正弹窗

播放页「全部字幕」列表点「校正」，可修改：

- 开始 / 结束时间（秒）
- 源语言原文、翻译译文

校验规则（R1.2）：

- 时间不得为负数
- 开始时间必须早于结束时间
- 结束时间不得超过媒体时长
- 不得与前一条重叠

!!! note "历史越界条目自动修复"

    Whisper 对结尾静音会幻觉出「ご視聴ありがとうございました」这类尾句，时间戳可能超出媒体长度。这类**历史**脏数据会在编辑/片段替换前被就地钳制到媒体时长，而不是让整份提交被拒；但**显式提交**的越界新值仍会被拒绝。

## 结构操作

| 操作 | 说明 |
|------|------|
| 合并下一条 | 用第一条开始、最后一条结束，允许先确认合并后的源文/译文 |
| 拆分此条 | 指定拆分时间 + 前后半原文/译文 |
| 删除此条 | 源字幕与翻译字幕一起删 |
| 撤销上次修改 | 恢复最近一次修改前快照 |
| 恢复自动版本 | 恢复自动生成的基线版本（会显示影响范围并要求确认） |
| 重处理此段 | 直接带起片段重处理表单 |

## 快照机制

- 每次正式写入前自动保存「上次修改前」快照
- 撤销/恢复都是**原子**操作：源字幕与翻译字幕要么都成功要么都不变
- 快照随 Library 迁移；SQLite 里不存字幕正文，字幕文件与快照才是事实来源

## 原则

- 字幕时间轴的**事实来源**是正式 SRT 文件，不信任模型输出的时间戳
- 模型只提供文本，时间由 SubForge 生成、校验、钳制
