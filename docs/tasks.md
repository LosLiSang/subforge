# 任务中心

所有在后台运行的工作——生成字幕、片段重跑、下载链接里的音频——都显示在「**任务中心**」。

![SubForge 任务中心](assets/images/readme/task-center.png){ .shot }

## 看懂任务列表

页面顶部有两个分页：**字幕生成任务**和**下载任务**。字幕任务下面还能按状态筛选，右侧可以搜索音轨名、作品名或 RJ 号。

每一行显示：

- **状态**；
- **音轨与作品**：处理的是哪条音轨、属于哪部作品；片段重跑还会显示时间范围；
- **模型配置**：用了哪个识别模型（ASR）和翻译模型；
- **进度**：当前进度、处理阶段、总耗时；
- **操作**：取消、重试、重新转写等。

开着「自动轮询刷新」时，列表每 3 秒自动更新一次。

## 任务状态

| 状态 | 意思 | 你可以做什么 |
|------|------|------------|
| 排队中 | 等前面的任务做完 | 取消 |
| 处理中 | 正在识别或翻译 | 取消 |
| 已完成 | 字幕已生成 | 重新转写 |
| 待确认 | 片段重跑完成，等你确认 | 查看候选、接受或放弃，见[片段重跑](segment-reprocess.md) |
| 无语音 | 没识别到人声（例如纯音效、纯环境音轨） | 正常现象，不是出错 |
| 失败 | 出错了，行内会显示原因 | 重试（会从中断的地方继续） |
| 已放弃 | 片段重跑的结果被你放弃了 | — |

## 常见情况

- **为什么任务一直在排队？** 默认本地识别同时只跑一个（避免显存不够）。可以在「设置 → 并发与性能」里调大，但显存小的电脑不建议。本地识别和在线识别各排各的队，互不影响。
- **翻译模型提示“请求太频繁”怎么办？** 不用管。SubForge 会自动等一会儿再试，连续多次没有任何进展才会算失败。
- **关掉软件，任务会丢吗？** 不会。下次启动时，没完成的任务会自动接着跑，已完成的记录也都保留。
